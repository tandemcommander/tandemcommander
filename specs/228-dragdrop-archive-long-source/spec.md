# Feature Specification: drag & drop into an archive lists the whole source folder

**Feature Branch**: `228-dragdrop-archive-long-source`
**Created**: 2026-10-15
**Status**: Implemented - see fix-log.md (not driven: needs drag & drop or the clipboard)

## Requirements *(mandatory)*

- **FR-001**: items dragged or pasted into an archive or a plug-in file system from a folder of any
  path length are described by that folder's listing - never by another folder's.
