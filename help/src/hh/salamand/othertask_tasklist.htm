Using Open Salamander Task List

Open Salamander Task List is intended to control execution of all running Open Salamander tasks (version 2.52 or later). The most important feature is possibility to break a not-responding task (do it from some responding Open Salamander task). The break makes the target task write a bug report to %LOCALAPPDATA%\Tandem Commander and show a message with the report's location; you can attach the report to an issue at github.com/tandemcommander/tandemcommander. This should help us to remove such bugs.

To break a not-responding (frozen) Open Salamander task:

  1. Start a new Open Salamander task.
  2. Open the Open Salamander Task List dialog box: Help/Task List.
  3. In the List of running Open Salamander tasks box select the not-responding task.

    Note Current task has "current process" appendix.

  4. Choose the Break button.
  5. The selected task writes a bug report to %LOCALAPPDATA%\Tandem Commander, shows a message with the report's location and closes.
  6. Attach the report to an issue at github.com/tandemcommander/tandemcommander if you want to help us fix the "hung" task.
