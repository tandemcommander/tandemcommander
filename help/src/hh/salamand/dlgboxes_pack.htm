Tandem Commander: Dialog Boxes

Pack

Use this dialog box to create archive from selected files and directories.

Dialog Box Options

Pack to archive
Enter the location of archive file you want to pack selected files and directories to.
Packer
Specify packer which will be used. The list contains the packers provided by plugins and the external packers. An external packer is listed only while its program is found: for example RAR (WinRAR), which creates RAR archives with WinRAR's console program (Rar.exe), appears once Rar.exe has been found by Archivers Autoconfiguration or its location has been set in External Archivers Locations. Packers you have added yourself are always listed. You can configure packers in Configuration/Archives/Packers in Pack Dialog.
Delete files from disk after packing to archive
When selected, files will be deleted after packing is successfully done.

Remarks

While an external packer runs, a small window with a Cancel button is shown. Cancel stops the packer; you are then told that the archive may be incomplete.
