Tandem Commander: Dialog Boxes

Archivers Autoconfiguration

Use this dialog box to find the external archivers Tandem Commander supports, the 7-Zip console program (7z.exe) and WinRAR's console program (Rar.exe), and add them to the configuration.

Dialog Box Options

Available archivers
Displays the supported external archivers and the programs found for them. When the dialog box opens, the usual installations of 7-Zip and WinRAR (found through their registry entries and in the Program Files folders) are already listed, without any search of your drives.
Add/Remove custom (un)packers
When selected, not only archives association in panels will be modified, but the entries of the archivers (the RAR (WinRAR) packer and the 7-Zip unpacker) will also be added to or removed from the lists in the Pack and Unpack dialog boxes. When not selected, these lists remain unmodified.
Drives
Opens a dialog allowing to specify which drives and directories the Start button searches.
Start
Searches the specified drives for 7z.exe and Rar.exe. Use it when an archiver is installed outside its usual location. While searching, the button changes to Stop.
