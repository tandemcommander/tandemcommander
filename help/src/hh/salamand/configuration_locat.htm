Tandem Commander: Dialog Boxes: Configuration

External Archivers Locations

Allows you to set where the external archivers are installed. The location is assigned to a variable that the packer, unpacker and panel commands of the archiver use. Tandem Commander supports two external archivers:

  • 7-Zip console program (7z.exe), variable $(SevenZipExecutable): lists (browses in a panel) and unpacks ARJ and LZH (LHA) archives, formats that no plugin reads. It is not used for packing.
  • WinRAR console program (Rar.exe), variable $(Rar32bitExecutable): creates RAR archives (the RAR (WinRAR) packer in the Pack dialog box) and packs files into them. It is used only for packing, not for reading RAR archives.

Dialog Box Options

External Archivers
Displays a list of external archivers supported by Tandem Commander.
List and Unpack
Displays the external archiver file name assigned to the selected variable in External Archivers. This archiver will be used for listing and unpacking content of archive.
Delete and Pack
Displays the external archiver file name assigned to the selected variable in External Archivers. This archiver will be used for deleting files from archive and packing files into archive. If selected archiver uses one program for all operations, Delete and Pack box will be disabled; this is the case for both supported archivers.

Remarks

An external archiver is used, and its entries in the Pack and Unpack dialog boxes and the archive formats it serves are offered, only while its program is found: the location set here must exist. A program name without a path is looked up the way Windows does (on the system path). While the program is not found, its entries are hidden and files with its extensions are treated as ordinary files, or opened by a plugin that supports them. After you install 7-Zip or WinRAR, use Options/Archivers Autoconfiguration to find it, or enter its location here; the entries appear at once.

Tandem Commander starts the archiver program directly. While it packs or unpacks, a small window with a Cancel button is shown; Cancel or Esc stops the archiver. While it reads an archive's list of files, Esc stops it. If the program cannot be started, the error message names the program and the reason.

Any other archiver can still be used: add it as your own packer or unpacker in Packers in Pack Dialog Box or Unpackers in Unpack Dialog Box with the full path of its program in the Command box. Such an archiver can pack and unpack, but its archives cannot be browsed in a panel unless a plugin or one of the supported archivers reads their format.
