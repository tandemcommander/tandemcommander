Tandem Commander: Dialog Boxes: Configuration

Tabs

Settings of the Tab Strip of the panels and of the keyboard shortcuts that work with tabs.

Dialog Box Options

Show tabs in panels
Shows a tab strip above the Directory Line of each panel. On by default. When you turn tabs off, the inactive tabs of both panels are closed (the program asks first), each panel keeps the tab it shows, and every key does what it does without tabs. The same switch is Tabs under Options > Show and in the context menu of the toolbars.
Browser-like tab shortcuts
Off by default. Turned on (and with tabs on), the keys known from web browsers work with tabs, in the panel and with the focus in the Command Line:

With the option on, Ctrl+Page Up and Ctrl+Page Down have no other key; Backspace still goes to the parent directory and Enter into the focused directory or archive. Ctrl+Tab moves between the panel and the Command Line in both modes. The keys shown in the menus (the Tabs submenus, Edit > Restore Selection, Commands > Go to Shortcut or Link Target) and in the tooltips follow the option. The option is unavailable while Show tabs in panels is off; it has no effect then.
Tab shortcuts
Lists the keys above with what they do in the mode the checkbox shows. Clicking Browser-like tab shortcuts updates the list at once, so you can compare both modes before you confirm the dialog.

Remarks

Reopen Closed Tab (in the Tabs submenus of the Left and Right menus and in the context menu of a tab) brings back the tab closed last in that panel, at its old position, with its directory, view, sort order, filter, cursor, selection and Back/Forward history. Close Tab, Close Other Tabs, Close Tabs to the Right and a middle click on a tab each remember the closed tabs one by one; a panel remembers the last 10. The list is kept in memory only: it is not saved with the configuration and is empty after a restart or after tabs were turned off. In the classic mode the command has no key.

A plugin command that you assigned Ctrl+Shift+G to in an earlier version keeps that key; with Browser-like tab shortcuts on, the program's command wins. A new plugin shortcut cannot use Ctrl+Shift+G.
