Tandem Commander: Customizing

Importing Settings from Salamander

If you used Altap Salamander (versions 2.5 to 4.0) or Open Salamander 5.0 before, the Import Settings from Salamander wizard brings your settings to Tandem Commander. Start it from the Options menu. When Tandem Commander starts for the first time and finds such settings, it offers the wizard once; answer Not now and it does not ask again — the command stays in the Options menu.

The old program's settings are only read; they are never changed. Nothing in Tandem Commander changes until you confirm the preview, and with the wizard's defaults nothing you already have in Tandem Commander is changed — only new items are added.

The Steps

Settings found
Lists the settings of Altap Salamander and Open Salamander found for your Windows user, newest first. Versions older than Altap Salamander 2.5, or written by a newer program, cannot be imported. A note tells you when the old program seems to be running (settings it has not saved yet are not seen) or when its last save may have been interrupted.
What to import
Each group shows the number of items found. Tick the groups you want. For hot paths, the user menu, FTP connections and shortcuts of plugin commands you choose the mode:
  • Add to my current settings (the default) keeps everything you have and adds what is new. An item you already have is not added twice; an item that would collide with yours (the same hot path slot, the same FTP connection name, a shortcut already in use) leaves yours as it is and is added in another form (the next free slot, a name with (imported)) or not at all.
  • Replace my current settings makes the group what the old program had; your current items in it are removed. For shortcuts of plugin commands it means that an imported shortcut wins over a plugin command's current one; shortcuts the old program does not mention stay as they are.
Viewers and editors are added after your rows for particular file types, so yours keep precedence; they come before your row for all files (*.*), so they take over the files that row opens today — the preview shows that as a change, and the group is unticked until you tick it. Groups that are sets of options (confirmations, panel and keyboard behaviour, general options, internal viewer settings, colours and highlighting, view templates, default directories, the settings of a plugin) take over the old program's values and are therefore unticked until you tick them. An option that works with masks or a text (for example Use Recycle Bin with its masks) is taken over together with them or not at all.
Saved passwords
Shown when FTP connections with saved passwords are imported. Passwords the old program stored without a Master Password come over (protected by your Tandem Commander Master Password if you use one). Passwords it protected with its Master Password come over only if you type that Master Password here; Tandem Commander then protects them like its own — under your Tandem Commander Master Password if you use one. If you do not, tick Store them without a Master Password to import them anyway, or set a Master Password first (Options > Configuration > Security) and run the import again.
Preview
Lists every change per group: + added, = already present, ~ replaced (current value → new value), - removed, ! imported but worth checking (for example a command that points into the old program's folder or to a program that no longer exists), x not imported and why. When anything of yours would be replaced or removed, Import is enabled only after you allow those changes.
Result
What really happened, the backup file of your previous settings and how to return to them. Copy and Save keep the report.

What is never imported

Archiver settings (use Options > Archivers Autoconfiguration), the installation of plugins, the language, the theme, panel tabs, toolbar layouts and window positions. Tandem Commander's own plugins and the file types they open stay as they are. Settings of plugins that Tandem Commander does not include are named in the result. Shortcuts of Tandem Commander's own commands cannot be changed, so only the shortcuts you gave to plugin commands are imported.

Returning to the previous settings

Before the first change the wizard saves all your current settings to %APPDATA%\Tandem Commander\Settings backups\before-import-<date>.reg. To go back, close Tandem Commander and start it with the parameter -C "<that file>", or double-click the file while Tandem Commander is closed (a running Tandem Commander would save its settings over the restored ones when it closes).

Remarks

Close other Tandem Commander windows before importing: they would overwrite the imported settings when they close. Close also the Find windows and the viewer windows: they use settings the import changes. A plugin whose archive or file system is open in a panel cannot take over its old settings until you close it. The import works on the same computer and Windows user as the old program.
