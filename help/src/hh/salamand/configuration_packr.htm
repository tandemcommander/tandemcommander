Tandem Commander: Dialog Boxes: Configuration

Packers in Pack Dialog Box

Allows you to manage packers used for Pack command.

Dialog Box Options

Name
Displays a list of all packers used for Pack command. You can reorder names according to your most often used packers.
Pack with
Packer used for selected packer name. It can be either external program or plugin.
Default extension
Extension used when new archive is created with Pack command.
Pack to archive
When external program is used for packing, Command specifies file name of used external archiver. For a supported external archiver (WinRAR), use its variable from External Archivers Locations; for any other archiver, enter the full path of its program. Arguments are parameters passed to the external program.
Pack to archive and then delete from disk
When external program is used for packing and deleting files may be supported, Command specifies file name of used external archiver. Using of variable from External Archivers Locations is recommended. Arguments are parameters passed to the external program.
Support long names
Check this check box when external archiver supports long file names. Otherwise clear this check box and Tandem Commander passes short (8.3) file names to the archiver. It has no effect on a list of files passed as $(ListUnicodeFullName).
Need List of Files in ANSI Charset
Check this check box if external program used for packing and deleting files requires list of files in ANSI charset. Clear this box if it requires list of files in OEM (console) charset. It has no effect on a list of files passed as $(ListUnicodeFullName), which is always written in Unicode.

Variables

The menu next to the Command box offers $(SevenZipExecutable) and $(Rar32bitExecutable), the program locations set in External Archivers Locations, and a command to browse for a program. The menu next to the Arguments box offers:

VariableDescription
$(ArchiveFullName) Full name of the archive.
$(ArchiveFileName) Name of the archive.
$(ArchivePath) Path to the archive.
$(ListFullName) Full name of the list of files, written in the OEM or ANSI code page (see Need List of Files in ANSI Charset).
$(ListUnicodeFullName) Full name of the list of files, written in Unicode (UTF-16). Use it for archivers that read such a list; names that the code page cannot represent are then passed unchanged.

The short-name (8.3) variables $(ArchiveDOSFullName), $(ArchiveDOSFileName) and $(ListDOSFullName) are no longer offered in the menu, but commands that already use them, or $(TargetDOSPath), keep working.
