Tandem Commander: Dialog Boxes: Configuration

Unpackers in Unpack Dialog Box

Allows you to manage unpackers used for Unpack command.

Dialog Box Options

Name
Displays a list of all unpackers used for Unpack command.
Unpack with
Unpacker used for selected unpacker name. It can be either external program or plugin.
File masks
File masks used to choose unpacker for selected archive when Unpack command is used. You can use also wildcard character '#' in these file masks. It stands for any digit ('0' ... '9').
Unpack archive
When external program is used for unpacking, Command specifies file name of used external archiver. For a supported external archiver (7-Zip), use its variable from External Archivers Locations; for any other archiver, enter the full path of its program. Arguments are parameters passed to the external program.
Support long names
Check this check box when external archiver supports long file names. For an unpacker, clearing it only limits the command line: a command longer than 127 characters is refused with an error instead of being started.
Need List of Files in ANSI Charset
Check this check box if external program used for unpacking files requires list of files in ANSI charset. Clear this box if it requires list of files in OEM (console) charset. It has no effect on a list of files passed as $(ListUnicodeFullName), which is always written in Unicode.

Variables

The menu next to the Command box offers $(SevenZipExecutable) and $(Rar32bitExecutable), the program locations set in External Archivers Locations, and a command to browse for a program. The menu next to the Arguments box offers:

VariableDescription
$(ArchiveFullName) Full name of the archive.
$(ArchiveFileName) Name of the archive.
$(ArchivePath) Path to the archive.
$(ListFullName) Full name of the list of files, written in the OEM or ANSI code page (see Need List of Files in ANSI Charset).
$(ListUnicodeFullName) Full name of the list of files, written in Unicode (UTF-16). Use it for archivers that read such a list; names that the code page cannot represent are then passed unchanged.

The short-name (8.3) variables $(ArchiveDOSFullName), $(ArchiveDOSFileName) and $(ListDOSFullName) are no longer offered in the menu, but commands that already use them, or $(TargetDOSPath), keep working.
