Open Salamander: Basic Working with Files and Directories

Quick Searching File or Directory Name

You can quickly find any desired name in the list of directories and files. Just start typing: every name that contains the typed text, at its start or anywhere inside it, matches. A name that starts with the text is focused first; when no name starts with it, a name that contains it is focused - typing "chat" finds "2024_chatbot". A character that no name contains is ignored.

While you type, the panel shows only the matching names, lightly tinted in the colours of your colour scheme, and its directory line shows the typed text and the number of matches, for example "Search: chat (3 of 120)". Use the arrow keys to move among the matches and Enter to open one. You can extend the text with Right arrow key (by the next character of the focused name), and on the contrary you can clip it with Left arrow key or Backspace key; the names that match again reappear. Escape key, or deleting the whole text, ends quick search and shows all names again with the cursor on the name it was on.

Commands (copy, move, delete, pack, select all, ...) work only on the names that are shown while searching: the selected ones among them, or the focused one. A name hidden by the search is never touched, and when it was selected, it is selected again when the search ends. The search ends when the panel goes to another directory, another tab or the other panel becomes active, and when a command creates or renames a name that does not match (it is then shown and focused); otherwise it lasts across commands, dialogs and refreshes.

While Open Salamander is in quick search mode, following keys are used for walking through files and directories which matches quick search mask: Up, Down, Page Up, Page Down, Home, End, Shift+Up, Shift+Down, Shift+Page Up, Shift+Page Down, Shift+Home, Shift+End, Alt+Up, Alt+Down, Alt+Home, and Alt+End. Keys with Shift modifier select or unselect files and directories and keys with Alt modifier walk only through selected files and directories. See Main Window Keyboard Shortcuts.

Advanced Usage

When you type slash (/), backslash (\), or less than (<) character, it will substitute any part of name (similar to '*' in file masks). Trailing dot (.) character is ignored when name has no extension. Examples:

When you typeIt will find names Corresponding file mask
/lefile.txt, less.exe, bmp.rle, etc.*le*
pro/.htmpromote.html, prototype.htm, professional.htm, etc.pro*.htm*
/.htmany.htm, page.htm, index.html, etc.*.htm*
/g.flag, flag.txt, etc. Note: it will not find name pic.jpg.*g.*

Note for German users: you can use the same key in English and German keyboard layout, because backslash (\) and less than (<) characters have the same functionality in quick search mode.

Remarks

When check box Redirect typing from panel to Command line in Configuration/Panels is checked, use Alt+letter to enter to quick search mode.

When check box Quick search finds text anywhere in names and shows only the matches in Configuration/Panels is cleared, quick search works as in earlier versions: only names that start with the typed text are found, all names stay visible, and the search ends with almost any command.
