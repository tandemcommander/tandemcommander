Tandem Commander: Customizing Tandem Commander

Archivers Autoconfiguration

You can let Tandem Commander find the external archivers it supports, the 7-Zip console program (7z.exe) and WinRAR's console program (Rar.exe), and set their locations for you.

To configure external archivers:

  1. Install 7-Zip or WinRAR, if you have not done so yet.
  2. Open the Archivers Autoconfiguration dialog box: open the Options menu and choose Archivers Autoconfiguration. The archivers installed in their usual locations are listed at once.
  3. If an archiver is installed elsewhere and is not listed, choose the Start button to search your drives, and wait until searching is finished.
  4. In the Available archivers box, check the archivers you want to add to the configuration.
  5. Choose the OK button.

The entries of the archivers you have added appear in the Pack and Unpack dialog boxes right away, and the archive formats they serve are recognized in panels.
