Tandem Commander: Dialog Boxes: Configuration

Archives Associations in Panels

Allows you to associate extensions to the archivers.

Dialog Box Options

File Extensions
Displays a list of extensions associated with archivers. More extensions can be associated with one archiver. Extensions are separated by semi-colon (;), character '#' stands for any digit ('0' ... '9').
List and Unpack
Displays the archiver name associated to the selected extensions in File Extensions. This archiver will be used for listing and unpacking of archive.
Delete and Pack
Displays the archiver name associated to the selected extensions in File Extensions. This archiver will be used for deleting files from archive and packing files into archive.

Note

An association served by an external archiver is used only while the archiver's program is found (see External Archivers Locations). Until then, files with its extensions are treated as ordinary files, or opened by a plugin that supports them; if only the program in Delete and Pack is missing, the archive can be listed and unpacked but not modified. By default, the 7-Zip console program lists and unpacks ARJ and LZH (LHA) archives. RAR archives cannot be opened yet; WinRAR's console program is used only to create them, from the Pack dialog box (RAR (WinRAR)).
