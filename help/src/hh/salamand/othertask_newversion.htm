Tandem Commander: Other Tasks

Checking for a New Version

Tandem Commander can tell you when a newer version has been published. It asks GitHub, where the project publishes its releases, which version is the latest, and compares it with the version you have. Only published releases with an installer are offered; pre-releases never are.

At start-up

Unless you turn it off, the program checks when it starts, at most once in 24 hours (when the server could not be reached at all, it tries again at a later start, at most once an hour). The check runs in the background and never delays the start. If a newer version exists, a window appears shortly after the main window. Without a connection, or when the server does not answer or answers unexpectedly, nothing is shown at all.

The window shows the version you have, the new version and the date it was released. It offers:

Download
Opens the installer of the new version in your web browser, which downloads it. Tandem Commander downloads and installs nothing itself. Run the installer to update; it closes the running program, replaces its files and starts it again. Your settings are kept.
Remind Me Later
Closes the window. The Esc key and the window's close button do the same. The window is shown again after the next check that finds the version, not sooner than the next day.
Skip This Version
Closes the window and does not show it at start-up again for this version. A still newer version is announced as usual. The skipped version remains visible in the About box and through the Help menu command.
Release notes
Opens the description of the new version in your web browser. The window stays open.
Check for a new version at start-up
The same option as on the General page of the configuration. Clearing it takes effect at once.

The window does not block the program: you can leave it open and continue working. Several running copies of Tandem Commander show only one such window.

On demand

Choose Help | Check for New Version to ask at any time, also when the check at start-up is turned off. The command always answers: with the window described above, with a message that your version is the latest, or with a message saying why the check could not be made. A check that takes longer shows a small window with a Cancel button.

In the About box

Help | About Tandem Commander shows, under your version, what the program last learned: that a newer version is available (with a Download link), that your version is the latest and when that was checked, or that no check has been made (with a Check now link). Opening the About box does not contact the server.

What is sent

One request to api.github.com over an encrypted connection, carrying the fixed identification TandemCommander-updatecheck. It does not contain the version you have, any identifier of you, your computer or the installation, or anything about your files and settings. No cookies are used. As with any web request, the server sees the IP address the request comes from. The privacy statement (PRIVACY.md in the project's repository) describes this in full.

Remarks

If you installed Tandem Commander with the Windows Package Manager, the command winget upgrade tandemcommander updates it too. A new version can reach the package catalogue a little later than it is announced here.

The version that introduced this feature could not announce itself: versions before it do not look for new versions.
