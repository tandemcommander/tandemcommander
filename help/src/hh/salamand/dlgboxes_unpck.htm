Tandem Commander: Dialog Boxes

Unpack

Use this dialog box to extract archive to disk.

Dialog Box Options

Unpack archive to
Specify the full or relative path to the destination directory (if it does not exist, it will be created).
Unpacker
Specify unpacker which will be used. The list contains the unpackers provided by plugins and the external unpackers. An external unpacker is listed only while its program is found: for example 7-Zip, which unpacks ARJ and LZH (LHA) archives with the 7-Zip console program (7z.exe), appears once 7z.exe has been found by Archivers Autoconfiguration or its location has been set in External Archivers Locations. Unpackers you have added yourself are always listed. You can configure unpackers in Configuration/Archives/Unpackers in Unpack Dialog.
Delete archive after unpacking
When selected, archive will be deleted after unpacking is successfully done. If it is multi-volume archive, all its volumes will be deleted.
Unpack files
Specify file names which will be extracted from archive. The default is *.*, it means that all files will be extracted.

Remarks

While an external unpacker runs, a small window with a Cancel button is shown. Cancel stops the unpacker.
